DEEP DIVE / LEVEL DATA

Separate game rules from level numbers.

“Three pieces clear” and “four or more leave a special” are shared rules. “Score 650 in 12 moves” is this level's data. A 0→1 ratio draws the swap first; the board rules resolve at contact.

IN THE REAL GAME

Load data into shared rules

Pass a different stage to newGame and the moves, target, and board all change. Update keeps the same swap rules.

type stage struct {
    moves       int
    targetScore int
    board       [rows][cols]int
}

func newGame(level stage) *game {
    return &game{level: level,
        board: level.board,
        moves: level.moves}
}

THE ONLY BOUNDARY

Update and Layout pass straight to the original game.

The native snapshot is the input-aligned playable surface. The edge inset uses Kage to keep only neighboring-pixel differences. The ASCII mock shows how a comparable game scene can communicate with characters alone. Rendering does not change the rules.

func (g *gallery) Update() error {
    return g.inner.Update()
}

func (g *gallery) Layout(w, h int) (int, int) {
    return g.inner.Layout(w, h)
}

func (g *gallery) Draw(screen *ebiten.Image) {
    snapshot := ebiten.NewImage(width, height)
    g.inner.Draw(snapshot)
    screen.DrawImage(snapshot, nil) // native-size playable input surface
    drawEdgeInset(screen, snapshot)
    drawASCIIGameMock(screen)

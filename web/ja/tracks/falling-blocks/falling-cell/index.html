DEEP DIVE / DROP TIMER

tickごとに動かさず、「時計」が満ちた時だけ落とす。

Ebitengine の Update は既定値で毎秒およそ60回呼び出されます。毎回の Update でブロックを1マス落下させると、わずか数十ミリ秒で床に到達してしまいます。そのため、経過 tick 数を変数 timer で計測し、規定の tick 数に達したときだけブロックを1マス進めます。

1

待った回数を数える

Update が呼ばれるたびに timer に 1 を加算します。画面下の黄色いゲージは、次の落下までの残り時間を可視化したものです。

timer++
2

マス単位で進む

timerが38になった時だけ行番号yへ1を足し、timerを0へ戻します。座標は小数ではなく盤面の行と列です。

if timer >= 38 { y++; timer = 0 }
3

進めないなら固定

次のマスが床か置いたブロックなら、動いているマスをboard[y][x]へ書き込み、新しいマスを上から出します。

board[y][x] = true; spawn()

THE TIMER RULE

timer++つぎにtimer が満タンなら y++（または固定）

速さを変えたいときは dropFrames を変えるだけ。位置の式は触りません。

IN THE REAL GAME

移動できるかを先に聞く

配列の外や使用中のマスへ入らないよう、次の行を調べてから落下か固定を選びます。

timer++
if timer >= dropFrames {
    timer = 0
    if !blocked(x, y+1) {
        y++
    } else {
        board[y][x] = true
        spawn()
    }
}

WHY A TIMER?

速さを数字で変えられる

dropFramesを小さくすれば、レベルが上がるほど速く落ちるルールも作れます。

WHY A GRID?

ぴったり積み上がる

行と列で管理すれば、ブロックが半端な位置で止まりません。

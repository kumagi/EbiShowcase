距離から接近・後退・攻撃を選ぶ

AIはプレイヤーの入力を読むのではなく、2人の距離を見ます。遠い、近い、攻撃できる、という3つの帯へ分ければ、間合いを取り合う相手になります。

01

遠距離

攻撃が届くまで近づきます。

02

近距離

反撃を避けるため少し下がります。

03

適正距離

予告動作のあとで技を出します。

SYSTEM LAB

距離から接近・後退・攻撃を選ぶ

距離を測る → 遠距離:接近 → 近距離:後退 → 適正距離で技 の順で進みます。NEXTで1段ずつ止めて、どの段階が新しい値を書くのか確かめましょう。

1

Update が担当

キー・タッチを読み、位置・HP・ゲージ・タイマー・盤面を変えます。判定やキュー操作もこちらです。

入力 → ルール → game を更新
2

Draw が担当

できあがった game の値を読んで、絵・文字・エフェクトを置きます。game の値は変えません。

game を読む → ピクセルへ投影

このページのルールは Update 側（または Update が呼ぶ純粋な関数）へ置き、Draw はその結果を表示するだけにします。

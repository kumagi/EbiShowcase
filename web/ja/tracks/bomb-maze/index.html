ボンバーマン型の爆風ゲームを作る

爆弾迷路アクション

ボンバーマンのような、迷路に爆弾を置いて壁や敵を吹き飛ばすゲームを作ります。時限爆弾から、上下左右に壁で止まるまで伸びていく十字の爆風、壊れる壁、連鎖爆発、アイテム、敵AIへ進みます。

共通基礎の続きです。LEVEL 01 の Update / Draw の上に、このジャンルの部品を1ステップずつ足します。主人公が登場するステップではオリジナルの 海老・天次郎（えび・てんじろう） を使います。

SPECIALIZATION / 好きなジャンルから開始

VFXは必要な時に戻る。
まず爆弾迷路アクションのルールを作る。

新しい課題は時限爆弾、壁で止まる十字爆風、壊れる壁、連鎖、アイテムです。
下の3つは演出で迷った時の参考ページです。未受講でも、このコースから始められます。

A12決定的エフェクト台本A06削除前スナップショットA08イベント列と演出予算

MOTION BASELINE

動いて見えることも完成条件

爆発をFuse→Flash→Flame→DebrisのCue台本にし、壁はSnapshot、連鎖爆発は型付き列で処理します。

TEST SEAM

派手さを外してもルールは同じ

爆風セル集合と連鎖順を純粋に試し、画面揺れや炎の寿命で当たり判定が増減しないこと。

はじめて読む人へ

LEARNING PATH

ひとつの仕組みから、
遊べる世界へ。

データの変化とアルゴリズムを小さなゲームで確かめ、前のステップを再利用しながら完成形へ進みます。

01

時限爆弾を置く

立っているマスへ爆弾を置き、一定時間後に状態を爆発へ変えます。

設置制限とタイマー
→ 02

十字に伸びる爆風

爆弾を置いたマスから上・下・左・右へ、爆風が1マスずつ伸びていくように調べ、固い壁に当たるか届く距離（射程）まで来たら止めます。

上下左右に伸びていく爆風の調べ方（4方向レイ探索）
→ 03

壊れる壁とアイテム

爆風を受けた壁を床へ変え、確率で能力アップを出現させます。

タイル変化と確率ドロップ
→ 04

爆弾の連鎖爆発

爆風が別の爆弾へ届いたら即座に爆発させ、その爆発が伝わっていきます（イベント伝播）。同じ爆弾を二度爆発させないよう記録しておきます（二重処理防止）。

爆発が次々伝わる仕組み（イベント伝播）と二重処理防止
→ 05

爆風から逃げる敵

これから爆風になるマスを予測して「危ないマス」の地図（危険マップ）を作り、そこを避けて安全な場所までの経路を探します。

危ないマスの地図（危険マップ）と安全経路
→ 06

爆発の予告と手応え

爆弾の脈動を速くし、爆発時に閃光・粒子・揺れを重ねます。

危険の予告と結果を時間でつなぐ
→ 07

3つの爆弾迷路を設計する

壁配置、必要破壊数、敵の開始位置が異なる3面をデータから読み込みます。

迷路と勝利条件をステージデータにする
→ 08

Ebi Bomber

爆弾数、火力、移動、敵、出口を統合して迷路アクションを完成させます。

能力アップ・敵・ステージ進行
